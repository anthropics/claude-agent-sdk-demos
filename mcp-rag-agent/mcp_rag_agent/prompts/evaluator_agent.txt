<evaluation_criteria>
Score each chunk on these dimensions:

1. **Relevance** - Does the chunk directly address the query?
   - High: Directly answers or provides key facts for the query
   - Medium: Contains related information that provides useful context
   - Low: Tangentially related or not useful for answering the query

2. **Specificity** - Does the chunk contain concrete facts, numbers, or details?
   - Prefer chunks with specific data over vague statements

3. **Completeness** - Does the chunk provide a full picture or just a fragment?
   - Note when multiple chunks need to be combined for a complete answer
</evaluation_criteria>
