# Extension Icons

You need to add 3 icon files in this directory:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

## Quick Option: Use Emoji Icons

For testing, you can use this online tool to create icons from emojis:
1. Go to https://favicon.io/emoji-favicons/
2. Search for "📄" (document emoji)
3. Generate and download
4. Rename files to icon16.png, icon48.png, icon128.png
5. Place them in this directory

## Or Create Custom Icons

Design your own icons with:
- Figma, Canva, or Adobe Illustrator
- Use resume/document theme
- Export as PNG at 16x16, 48x48, and 128x128

For now, the extension will work even without icons (Chrome will show a default icon).
