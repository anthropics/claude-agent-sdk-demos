Installation Instructions

1

Download the Extension

Click the download button above to get the extension package.

Download resume-tailor-extension.tar.gz
2

Extract the Archive

Extract to a permanent location (don't delete after installing!)

Windows: Right-click → Extract All
Mac: Double-click or use Archive Utility
Linux: tar -xzf resume-tailor-extension.tar.gz
3

Open Chrome Extensions

Type in your Chrome address bar:

chrome://extensions/

Or: Chrome Menu (⋮) → Extensions → Manage Extensions

4

Enable Developer Mode

Toggle the "Developer mode" switch in the top-right corner.

📍 Look for: A toggle switch labeled "Developer mode" at the top-right of the page
5

Load Unpacked Extension

Click "Load unpacked" button and select the extracted folder.

Important:

Select the extracted folder, not the .tar.gz file!
The folder should contain manifest.json, popup.html, etc.

✓

Extension Installed! 🎉

You should see "Resume Tailor - AI-Powered Resume Optimization" in your extensions list.

💡 Pro Tip: Pin the extension

Click the puzzle icon (🧩) in Chrome toolbar → Find "Resume Tailor" → Click pin icon 📌
This makes the extension always visible in your toolbar!

How to Use

1
Navigate to any job posting

LinkedIn, Indeed, Glassdoor, company career pages, etc.

2
Click the extension icon

Look for 📄 icon in your Chrome toolbar (pin it for easy access!)

3
Upload your resume (.docx)

4

✓
Download your tailored resume!

Ready to apply in under 5 minutes ⚡

Troubleshooting

Extension icon doesn't appear:

Refresh chrome://extensions/ and click the reload icon on the extension

Can't extract job description:

Refresh the job page first, or try a different job site. Use manual paste as backup.

Server connection error:

Make sure the server is running. Visit health check
